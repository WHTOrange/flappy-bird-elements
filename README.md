游戏机制简介:
该游戏为飞翔的小鸟的一个变种，我在游戏中增加了7种元素，这7种元素之间互相可以反应，产生不同的效果，并且元素单独也会产生不同的效果
 一、 基础元素单吃效果
拾取单元素后，头顶 UI 会显示元素附着，并获得对应效果：
风：重力减弱，气流保护。
火：无敌加速。
水：恢复生命。
冰：全局减速。
雷：向前突进。
岩：获得护盾。
草：生成节点，点击飞向。
二、 元素反应（两两结合触发）
火 + 水：隐身无敌，吸附金币。
火 + 冰：可无视碰撞穿过冰柱。
火 + 草：焚毁前方柱子。
火 + 风：重力极轻极重乱跳。
火 + 雷：极速无敌，突进粉碎柱子。
火 + 岩：化身岩浆球，撞碎柱子。
风 + 水：浓雾遮蔽视野。
风 + 冰：长按起飞，全局减速。
风 + 雷：重力反转往下飞。
风 + 草：自动吸附金币。
风 + 岩：柱子被侵蚀，缝隙增大。
水 + 冰：柱子被冻碎。
水 + 草：生成滑道。
水 + 雷：高频抽搐，操作延迟。
水 + 岩：跳跃高度递减。
雷 + 冰：强制倒退。
雷 + 草：连续穿梭雷印。
雷 + 岩：遁入幻境
冰 + 草：生成冰道。
冰 + 岩：柱子上下震动。
岩 + 草：重力翻倍。
三、 特殊机制
盲盒机制：地图掉落彩虹盲盒，拾取后随机触发上述某一种元素
分数机制：连续吃金币叠加倍率，受伤断连则重置
彩虹柱子机制：每隔60秒会刷新一根彩虹柱子，穿过必定会获得一种元素附着效果
